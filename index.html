Teknik Substitusi, Parsial, dan Lainnya

🔄 Kapan Menggunakan Substitusi?

🎯 Ciri-ciri Integral yang Cocok untuk Substitusi:

✓ Ada fungsi dalam fungsi (komposit)
• ∫ (x² + 1)⁵ · 2x dx → fungsi dalam: x² + 1, fungsi luar: u⁵
• ∫ sin(3x) dx → fungsi dalam: 3x, fungsi luar: sin u
• ∫ e^(2x) dx → fungsi dalam: 2x, fungsi luar: e^u
• ∫ √(x² + 4) · x dx → fungsi dalam: x² + 4, fungsi luar: √u
✓ Ada turunan dari fungsi dalam
• ∫ x(x² + 1)⁵ dx → x adalah turunan dari x² + 1 (kecuali konstanta 2)
• ∫ cos x · sin³x dx → cos x adalah turunan dari sin x
• ∫ e^x · (e^x + 1)² dx → e^x adalah turunan dari e^x + 1
• ∫ (1/x) · ln²x dx → 1/x adalah turunan dari ln x
✓ Bentuk f(g(x)) · g'(x) - pola klasik substitusi
• ∫ 2x · e^(x²) dx → f(u) = e^u, g(x) = x², g'(x) = 2x
• ∫ 3x² · cos(x³) dx → f(u) = cos u, g(x) = x³, g'(x) = 3x²
• ∫ sec²x · tan⁴x dx → f(u) = u⁴, g(x) = tan x, g'(x) = sec²x
✓ Integral trigonometri dengan pangkat ganjil
• ∫ sin³x dx = ∫ sin²x · sin x dx → substitusi u = cos x
• ∫ cos⁵x dx = ∫ cos⁴x · cos x dx → substitusi u = sin x
• ∫ sin⁷x · cos x dx → substitusi u = sin x
⚠️ PENTING: Tidak harus SEMUA ciri ada! Cukup SATU ciri saja sudah bisa pakai substitusi!

⚡ Trik Cepat Mengenali Substitusi:

LIHAT TURUNAN! Jika ada faktor yang merupakan turunan dari bagian lain → SUBSTITUSI!
Contoh: ∫ 2x(x² + 1)⁵ dx → 2x adalah turunan dari x² + 1
Contoh: ∫ sin x · cos³x dx → sin x = -(cos x)'
Contoh: ∫ e^x · sin(e^x) dx → e^x adalah turunan dari e^x

1. Integral dengan Substitusi

Teknik substitusi digunakan ketika integral mengandung fungsi komposit. Kita mengganti bagian dari integral dengan variabel baru.

∫ f(g(x)) · g'(x) dx = ∫ f(u) du, dimana u = g(x)

Langkah-langkah:

1. Pilih substitusi u = g(x)
2. Hitung du = g'(x) dx
3. Ganti semua x dengan u
4. Integralkan terhadap u
5. Kembalikan ke variabel x

📋 Pola Substitusi untuk Fungsi Aljabar:

• ∫ (ax + b)^n dx → u = ax + b, du = a dx
• ∫ x · f(x²) dx → u = x², du = 2x dx
• ∫ f(√x) / √x dx → u = √x, du = dx/(2√x)
• ∫ f(ln x) / x dx → u = ln x, du = dx/x
• ∫ e^(ax) dx → u = ax, du = a dx

📋 Pola Substitusi untuk Fungsi Trigonometri:

• ∫ sin x · f(cos x) dx → u = cos x, du = -sin x dx
• ∫ cos x · f(sin x) dx → u = sin x, du = cos x dx
• ∫ sec²x · f(tan x) dx → u = tan x, du = sec²x dx
• ∫ sin(ax) atau cos(ax) dx → u = ax, du = a dx

Contoh Substitusi Aljabar:

∫ (2x + 3)⁵ dx

u = 2x + 3, du = 2dx → dx = du/2
∫ u⁵ · (du/2) = (1/2) ∫ u⁵ du = (1/12)u⁶ + C
= (1/12)(2x + 3)⁶ + C

Contoh Substitusi Trigonometri:

∫ sin x · cos³x dx

u = cos x, du = -sin x dx
∫ sin x · cos³x dx = ∫ u³ · (-du) = -∫ u³ du
= -(1/4)u⁴ + C = -(1/4)cos⁴x + C

🔗 Kapan Menggunakan Parsial?

🎯 Ciri-ciri Integral yang Cocok untuk Parsial:

✓ Hasil kali 2 fungsi berbeda jenis
• ∫ x · e^x dx → aljabar (x) × eksponensial (e^x)
• ∫ x² · sin x dx → aljabar (x²) × trigonometri (sin x)
• ∫ ln x · x dx → logaritma (ln x) × aljabar (x)
• ∫ x · cos(2x) dx → aljabar (x) × trigonometri (cos 2x)
• ∫ e^x · sin x dx → eksponensial (e^x) × trigonometri (sin x)
✓ Satu fungsi mudah diturunkan, satu mudah diintegralkan
• ∫ x · e^x dx → x mudah diturunkan (jadi 1), e^x mudah diintegralkan (tetap e^x)
• ∫ x² · cos x dx → x² mudah diturunkan (jadi 2x), cos x mudah diintegralkan (jadi sin x)
• ∫ ln x dx → ln x mudah diturunkan (jadi 1/x), konstanta 1 mudah diintegralkan (jadi x)
✓ Tidak bisa diselesaikan dengan substitusi
• ∫ x · e^x dx → tidak ada turunan yang cocok untuk substitusi
• ∫ x · sin x dx → x bukan turunan dari sin x, dan sin x bukan turunan dari x
• ∫ ln x dx → tidak ada pola f(g(x))·g'(x)
⚠️ Bandingkan dengan ∫ x · sin(x²) dx yang BISA substitusi karena x adalah turunan dari x²!
✓ Ada logaritma atau invers trigonometri
• ∫ ln x dx → logaritma selalu pilih sebagai u dalam parsial
• ∫ x · ln x dx → ln x sebagai u, x sebagai dv
• ∫ arcsin x dx → invers trigonometri selalu pilih sebagai u
• ∫ x · arctan x dx → arctan x sebagai u, x sebagai dv
💡 Aturan LIATE: Logaritma dan Invers selalu prioritas pertama untuk u!
⚠️ PENTING: Tidak harus SEMUA ciri ada! Cukup SATU ciri saja sudah bisa pakai parsial!

⚡ Trik Cepat LIATE untuk Memilih u:

Logaritma (ln x, log x) → SELALU PILIH SEBAGAI u!
Invers Trigonometri (arcsin x, arctan x) → PILIH SEBAGAI u!
Aljabar (x, x², x³) → Pilih u jika ada L atau I
Trigonometri (sin x, cos x) → Biasanya dv
Eksponensial (eˣ, e^(2x)) → Biasanya dv

🚫 Kapan JANGAN Pakai Parsial:

✗ Jika bisa substitusi - ∫ x(x² + 1)⁵ dx → substitusi lebih mudah!
✗ Fungsi sejenis - ∫ sin x cos x dx → gunakan identitas trigonometri
✗ Integral dasar - ∫ x² dx, ∫ sin x dx → langsung integralkan

2. Integral Parsial

Teknik parsial digunakan untuk integral hasil kali dua fungsi yang berbeda jenis.

∫ u dv = uv - ∫ v du

Tips memilih u (LIATE):

Logaritma → Invers Trigonometri → Aljabar → Trigonometri → Eksponensial

📋 Pola Parsial untuk Fungsi Aljabar:

• ∫ x^n · eˣ dx → u = x^n, dv = eˣ dx (parsial n kali)
• ∫ x^n · sin(ax) dx → u = x^n, dv = sin(ax) dx
• ∫ x^n · cos(ax) dx → u = x^n, dv = cos(ax) dx
• ∫ ln x dx → u = ln x, dv = dx
• ∫ x^n · ln x dx → u = ln x, dv = x^n dx

📋 Pola Parsial untuk Fungsi Trigonometri:

• ∫ x · sin x dx → u = x, dv = sin x dx
• ∫ x · cos x dx → u = x, dv = cos x dx
• ∫ eˣ · sin x dx → u = eˣ, dv = sin x dx (parsial 2 kali, dapat persamaan)
• ∫ eˣ · cos x dx → u = eˣ, dv = cos x dx (parsial 2 kali, dapat persamaan)
• ∫ arcsin x dx → u = arcsin x, dv = dx

💡 Trik Khusus Parsial Berulang:

Untuk ∫ eˣ sin x dx dan ∫ eˣ cos x dx, parsial 2 kali akan menghasilkan persamaan yang bisa diselesaikan!

Contoh Parsial Aljabar:

∫ x² · eˣ dx

u = x², dv = eˣ dx → du = 2x dx, v = eˣ
∫ x² · eˣ dx = x² · eˣ - ∫ eˣ · 2x dx
= x² · eˣ - 2∫ x · eˣ dx
Parsial lagi: u = x, dv = eˣ dx
= x² · eˣ - 2[x · eˣ - ∫ eˣ dx]
= eˣ(x² - 2x + 2) + C

Contoh Parsial Trigonometri:

∫ x · cos x dx

u = x, dv = cos x dx → du = dx, v = sin x
∫ x · cos x dx = x · sin x - ∫ sin x dx
= x · sin x - (-cos x) + C
= x · sin x + cos x + C

Contoh 1: Integral Substitusi

Soal: ∫ 2x(x² + 1)⁵ dx

Penyelesaian:

Misalkan u = x² + 1
Maka du = 2x dx
∫ 2x(x² + 1)⁵ dx = ∫ u⁵ du
= (1/6)u⁶ + C
= (1/6)(x² + 1)⁶ + C

Contoh 2: Integral Parsial

Soal: ∫ x · eˣ dx

Penyelesaian:

Misalkan u = x dan dv = eˣ dx
Maka du = dx dan v = eˣ
∫ x · eˣ dx = x · eˣ - ∫ eˣ dx
= x · eˣ - eˣ + C
= eˣ(x - 1) + C

Contoh 3: Integral Trigonometri

Soal: ∫ sin²x dx

Penyelesaian:

Gunakan identitas: sin²x = (1 - cos 2x)/2
∫ sin²x dx = ∫ (1 - cos 2x)/2 dx
= (1/2) ∫ (1 - cos 2x) dx
= (1/2)[x - (1/2)sin 2x] + C
= (1/2)x - (1/4)sin 2x + C

Contoh 4: Integral dengan Substitusi Trigonometri

Soal: ∫ √(1 - x²) dx

Penyelesaian:

Misalkan x = sin θ, maka dx = cos θ dθ
√(1 - x²) = √(1 - sin²θ) = cos θ
∫ √(1 - x²) dx = ∫ cos θ · cos θ dθ = ∫ cos²θ dθ
= ∫ (1 + cos 2θ)/2 dθ = (1/2)[θ + (1/2)sin 2θ] + C
= (1/2)arcsin x + (1/2)x√(1-x²) + C

⚡ Contoh Khusus: Integral yang Bisa Dikerjakan dengan Kedua Teknik

Contoh 5A: ∫ x·cos(x²) dx - Cara Substitusi

Penyelesaian dengan Substitusi:

Misalkan u = x², maka du = 2x dx → x dx = du/2
∫ x·cos(x²) dx = ∫ cos(u) · (du/2)
= (1/2) ∫ cos(u) du = (1/2) sin(u) + C
= (1/2) sin(x²) + C

✓ Cara ini LEBIH MUDAH karena langsung mengenali pola substitusi!

Contoh 5B: ∫ x·cos(x²) dx - Cara Parsial

Penyelesaian dengan Parsial:

Misalkan u = x dan dv = cos(x²) dx
Maka du = dx dan v = ? (sulit mencari ∫cos(x²) dx!)
❌ Cara ini TIDAK PRAKTIS karena ∫cos(x²) dx tidak mudah!

✗ Untuk soal ini, substitusi jauh lebih efisien!

💡 Kesimpulan:

Meskipun secara teori beberapa integral bisa dikerjakan dengan kedua teknik, dalam praktiknya selalu ada satu cara yang jauh lebih efisien. Kunci sukses adalah mengenali pola dan memilih teknik yang tepat!
